# calculadora-python
Calculadora desenvolvida em python pra eu colocar em prática os exercícios que fiz até aqui, me desafiar um pouco e praticar git.

Explicação do projeto: Exibir no terminal 4 opções, somar, subtrair, multiplicar e dividir números (inicialmente apenas dois números, mas pretendo evoluir para até quantos o usuário quiser).
    
    Estrutura: Cada calculo será uma função, o menu será uma função, de acordo com a opção que o usuário escolher no terminal chamará a função do calculo e o realizará.
