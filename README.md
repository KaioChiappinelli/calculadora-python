# calculadora-python

## Sobre o projeto
Calculadora desenvolvida em python - Meu primeiro projeto prático de programação em python do github, pratiquei os conceitos que estou aplicando nesse projeto em exercícios, atividades e trabalhos da faculdade. Então decidi começa-lo com intuito de praticar conceitos de forma mais independente e desafiadora (principalmente por ser sem IA pra gerar codigo), ir evoluindo o projeto progressivamente e também treinar o uso de git e github

## Conceitos aplicados

1. **Variáveis e Tipagem:** armazenamento dos operandos, opções de operação e resultados, com utilização de tipagem explícita (`float`, `int` e `tuple`).

2. **Estruturas Condicionais (`match/case`):** controle do fluxo de execução por meio de um menu interativo, direcionando o programa conforme a operação escolhida.

3. **Estruturas de Repetição (`while/for`):** Para manter o menu ativo, permitir novas operações, repetir solicitações em caso de entradas inválidas e realizar operações com dois ou mais números (`for`).

4. **Funções e Modularização:** divisão do programa em funções com responsabilidades específicas, separando as operações matemáticas, a entrada de dados e o controle do menu.

5. **Tratamento de Exceções (`try/except`):** identificação e tratamento de erros durante a execução como entradas numéricas inválidas e tentativas de divisão por zero.

6. **Controle de Fluxo (`break/continue`):** interrupção dos laços de repetição para controlar o encerramento do programa e a saída das estruturas de execução.

7. **Formatação de Strings (f-strings):** utilização de interpolação de variáveis para apresentar dinamicamente os cálculos e seus respectivos resultados.
