# calculadora-python

## Sobre o projeto
Calculadora desenvolvida em python - Meu primeiro projeto prático de programação em python do github, até então só pratiquei os conceitos que estou aplicando nesse projeto em exercícios relativamente básicos, atividades e trabalhos da faculdade. Então decidi começa-lo com intuito de praticar conceitos de forma mais independente e desafiadora (principalmente por ser sem IA pra gerar resposta e codigo apenas pra auxílio com sintaxes e duvidas), ir evoluindo o projeto progressivamente e também treinar o uso de git e github

## Estrutura
Cada calculo é uma **função** com parametros e argumentos padrões passados e retornando o resultado do calculo, os valores só são atribuidos ás funções durante a chamada delas no **match case** e exibindo o resultado num **f string**.
