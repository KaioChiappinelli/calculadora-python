# calculadora-python

## Sobre o projeto
Calculadora desenvolvida em python - Meu primeiro projeto prático de programação em python do github, pratiquei os conceitos que estou aplicando nesse projeto em exercícios, atividades e trabalhos da faculdade. Então decidi começa-lo com intuito de praticar conceitos de forma mais independente e desafiadora (principalmente por ser sem IA pra gerar codigo), ir evoluindo o projeto progressivamente e também treinar o uso de git e github

## Funcionalidades
- Soma
- Subtração
- Multiplicação
- Divisão

## Estrutura
- Cada calculo é uma **função** com parâmetros, argumentos padrões passados e retornando o resultado do calculo.
- Os valores só são atribuidos ás funções durante a chamada delas no **match case** e exibindo o resultado num **f string**.
- Loop while no chamar_funcoes que permite que o usuário faça uma operação, volte ao menu repita ou faça outra operação, só encerrando o programa quando digita "5".
